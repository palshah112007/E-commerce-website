# Novamart Storefront

A complete ecommerce website with React frontend, Vite API backend, and a JSON database.

## Setup

1. Run `npm install`
2. Run `npm run dev`

Frontend: http://127.0.0.1:5174
Backend API: http://127.0.0.1:5174/api
Database: `database/db.json`

## Features

- Original ecommerce homepage layout
- Product search and category filters
- Product detail pages with image galleries
- Shopping cart with quantity updates
- Backend API for products, cart, and checkout orders
- File-backed JSON database
