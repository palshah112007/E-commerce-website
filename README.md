# Novamart Storefront

A standalone ecommerce storefront built with React and Vite.

## Setup

1. Open a terminal in this project folder
2. Run `npm install`
3. Run `npm run server`
4. Open a second terminal and run `npm run dev`

Frontend: http://127.0.0.1:5173
Backend API: http://127.0.0.1:4000/api
Database: `database/db.json`

## Features

- Original ecommerce homepage layout
- Product search and category filters
- Product detail pages
- Shopping cart with quantity updates
- Backend API for products, cart, and checkout orders
- File-backed JSON database
